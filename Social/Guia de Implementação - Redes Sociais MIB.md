## Configurações Importantes

### Todas as Redes
- Usar sempre o mesmo nome de usuário quando possível
- Manter consistência visual (cores, logo, fontes)
- Adicionar links cruzados entre as redes
- Configurar contas comerciais/empresariais

### Monitoramento
- Configurar Google Analytics para o site
- Usar ferramentas de agendamento (Buffer, Hootsuite)
- Monitorar menções à marca
- Acompanhar métricas de engajamento

## Dicas de Gestão

### Conteúdo
- Manter calendário editorial
- Balancear conteúdo promocional e educativo
- Responder comentários rapidamente
- Usar stories/reels para maior alcance

### Engajamento
- Interagir com outros perfis do setor
- Participar de conversas relevantes
- Usar hashtags estratégicas
- Colaborar com influenciadores do setor

### Crescimento
- Investir em anúncios pagos quando necessário
- Fazer parcerias com outras empresas
- Participar de eventos do setor
- Criar conteúdo viral (quando apropriado)

## Especificações Técnicas dos Banners

### Dimensões Recomendadas por Plataforma
- **YouTube:** 2560 x 1440 pixels (área segura: 1546 x 423 pixels)
- **LinkedIn:** 1584 x 396 pixels
- **Instagram:** 1080 x 1080 pixels (posts) ou 1080 x 1920 pixels (stories)
- **TikTok:** 1080 x 1920 pixels
- **Google My Business:** 1080 x 608 pixels

### Elementos Visuais Consistentes
- Logo MIB com mangueira verde escura
- Texto "EQUIPAMENTOS CONTRA INCÊNDIO" em português
- Cores da marca: preto, verde escuro, laranja/vermelho
- Tipografia moderna e legível
- Elementos de segurança e confiança
