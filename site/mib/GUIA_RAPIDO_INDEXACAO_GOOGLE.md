## ⚠️ PROBLEMAS COMUNS E SOLUÇÕES

### "Descoberta - Não indexada no momento"

**NORMAL!** Significa que:
- Google descobriu a página ✅
- Está na fila para rastreamento
- Aguarde 7-14 dias

**Acelerar:** Solicite indexação manual

---

### "Rastreada - não indexada no momento"  

**Possíveis causas:**
1. Conteúdo duplicado
2. Conteúdo muito fino (pouco texto)
3. Problemas técnicos

**Solução:**
- Verifique se há conteúdo suficiente (300+ palavras)
- Garanta que cada página tem conteúdo único
- Verifique se não há duplicate content

---

### Páginas aparecem SEM descrição no Google

**Causa:** Google está usando trechos do conteúdo ao invés da meta description

**Solução:**
1. Melhorar a meta description
2. Torná-la mais relevante para a pesquisa
3. Incluir palavras-chave principais
4. Adicionar CTA (call-to-action)

**Exemplo de meta description otimizada:**
```
Mangueiras de incêndio certificadas ABNT NBR 11861 em SP. Tipos 1 a 5, 
15-30m. Entrega rápida. Orçamento grátis ✆ (11) 94025-8669 | MIB Brasil
```

## 🆘 PROBLEMAS? VERIFICAÇÕES RÁPIDAS

### "Minhas páginas não aparecem no Google depois de 7 dias"

**Verificar:**

1. ✅ Sitemap foi submetido? (Search Console → Sitemaps)
2. ✅ Sitemap foi processado sem erros?
3. ✅ Robots.txt não está bloqueando? (Verificar em Search Console)
4. ✅ Páginas têm conteúdo suficiente? (300+ palavras)
5. ✅ Meta robots está como "index, follow"? (Sim ✅)

**Se tudo OK e ainda não indexou:**
- Aguarde mais 7-14 dias
- Solicite indexação manual novamente
- Verifique se há conteúdo duplicado

---

### "Páginas aparecem sem descrição no Google"

**Isso é NORMAL inicialmente!**

Google pode demorar para:
1. Processar meta descriptions
2. Decidir qual descrição usar
3. Atualizar o snippet nos resultados

**Solução:**
- Aguarde 14-30 dias
- Se persistir, otimize a meta description
- Garanta que a meta description tem 150-160 caracteres
- Inclua palavras-chave principais
