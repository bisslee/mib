# Paleta de Cores MIB - Equipamentos Contra Incêndio

## Cores Principais do Logotipo

### 🔥 Laranja Principal (Chama/Tagline)
- **Hex:** #E55A2B
- **RGB:** 229, 90, 43
- **Uso:** Elementos de destaque, botões principais, chama do logo, tagline

### 🌿 Verde Escuro (Mangueira)
- **Hex:** #2D5A4A
- **RGB:** 45, 90, 74
- **Uso:** Mangueira do logo, elementos secundários, navegação

### ⚫ Preto (Texto Principal)
- **Hex:** #1A1A1A
- **RGB:** 26, 26, 26
- **Uso:** Texto MIB, títulos principais, texto de alta hierarquia

## Diretrizes de Uso

### Contraste e Acessibilidade
- Sempre verificar contraste mínimo de 4.5:1 para texto normal
- Contraste mínimo de 3:1 para texto grande (18pt+)
- Usar cores neutras para grandes blocos de texto

### Hierarquia Visual
- **Primário:** Laranja (ações principais, destaques)
- **Secundário:** Verde (navegação, estrutura)
- **Terciário:** Neutros (conteúdo, texto)

### Proporções Recomendadas
- **60%** Neutros (brancos, cinzas)
- **30%** Verde (estrutura, navegação)
- **10%** Laranja (destaques, CTAs)

Esta paleta mantém a identidade visual do logotipo MIB enquanto oferece flexibilidade suficiente para criar um website moderno, profissional e acessível.
